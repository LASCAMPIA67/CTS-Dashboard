# CTS Dashboard

Widget iPhone permettant aux conducteurs CTS de consulter leur service directement depuis l’écran d’accueil.

**Développé par Emilio IPPOLITO — Matricule 6124**

> CTS Dashboard est un projet indépendant. Il ne remplace pas les documents de service officiels.

# Installation

## 1. Installer Scriptable

Téléchargez gratuitement l’application **Scriptable** depuis l’App Store.

Ouvrez ensuite Scriptable une première fois.

---

## 2. Télécharger CTS Installer

Ouvrez le fichier suivant :

[📥 Télécharger CTS Installer](https://github.com/LASCAMPIA67/CTS-Dashboard/blob/main/CTS%20Installer.js)

Sur la page du fichier :

1. Appuyez sur les trois points `…`.
2. Choisissez **Download raw file** ou **Télécharger le fichier brut**.
3. Enregistrez le fichier dans :
